# skysight 专业天气产品 Demo

这是一个创业汇报配套的交互式静态网页，面向施工、农业和畜牧等专业个人，并演示能源、航空和轨交企业天气服务。

## 体验内容

- 按地点、任务和工作时段查看天气示例。
- 比较同一份合成数据的区域小时值和作业点10分钟值。
- 在施工、农田和牧场布置图中切换近邻作业点。
- 比较连续任务的候选时段，设置本机提醒和准备清单。
- 查看企业服务情景并导出文本简报。

## 数据说明

天气、功率、工作安排和作业布置均为合成示例，不是实时天气、真实客户案例或预测准确率证据。细网格与短时间步长不自动等于更高准确率。任务比较不作为安全、适宜性、飞行放行或轨道运行决定的依据。

真实地理底图通过OpenStreetMap官方嵌入地图提供，需要联网；作业布置图可离线展示。地图署名为 [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)。地区参考选点不代表实际项目坐标。

提醒与准备记录仅保存在当前浏览器，不会发送短信、微信或系统通知，也没有持续后台监测。会员仅用于交互体验，不注册、不收费。

## 静态部署

网页入口是根目录的 `index.html`，所有应用CSS、JavaScript与作业示意图均已内联，无需构建或安装依赖。仓库包含 `.nojekyll`，可以通过GitHub Pages从发布分支根目录部署。
